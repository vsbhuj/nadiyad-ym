# જન્મદિન મંગલોત્સવ

**શ્રી નરનારાયણદેવ યુવક-યુવતી મંડળ, નડિયાદ** – સભ્યોના જન્મદિવસના રિમાઇન્ડર અને શુભેચ્છા માટેની વેબ એપ.

## શું છે
- **હોમ:** આજના જન્મદિવસવાળા સભ્યનો ફોટો કમળની ફ્રેમમાં, નામ અને ઉંમર સાથે.
- **મંગલ શુભકામનાઓ પાઠવો:** ફટાકડા અને કમળની પાંખડીઓ સાથે ઉજવણી, પછી તૈયાર સંદેશ સાથે WhatsApp.
- **આગામી જન્મદિવસ, કેલેન્ડર, સભ્યોની યાદી, રિમાઇન્ડર** (આવતીકાલે અને ૭ દિવસ પહેલા).

## ફાઇલો
| ફાઇલ | શું છે |
|---|---|
| `index.html` | આખી એપ |
| `*.png`, `bg.jpg` | ડિઝાઇનની ઇમેજ |
| `members.csv` | ૮૫ સભ્યોના નામ અને જન્મતારીખ |
| `mandal_birthdays.ics` | Google Calendar માં ઇમ્પોર્ટ કરવાની ફાઇલ (દર વર્ષે રિપીટ, રિમાઇન્ડર સાથે) |

## ચલાવવું
GitHub Pages ચાલુ કરો: **Settings → Pages → Branch: `main` / root → Save**. થોડી મિનિટમાં લિંક મળશે.

> નોંધ: GitHub Pages પર એપ જોઈ શકાય છે, પણ મોબાઇલ નંબર અને ફોટો સેવ કરવાનું ફક્ત claude.ai વાળી લિંકમાં ચાલે છે.
